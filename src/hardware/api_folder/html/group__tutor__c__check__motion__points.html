Checking PVT points

The tutorial demonstrates how to verify validity of PVT points in a servo trajectory without actually connecting a servo, while checking for PVT velocities over maximum limits. Maximum velocity limits (degrees per seconds) for RDrive motors (@48V):

  • RD50: 267.84 ~= 260
  • RD60: 267.84 ~= 260
  • RD85: 244.80 ~= 240

point_t points[] = {
{343.77, 0, 0},
{202.57, 1.33, 1537.4},
{205.63, 9.20, 1148.9},
{210.00, 21.24, 277.9},

{230.14, 52.62, 161.8},
{238.85, 60.75, 152.6},
{248.41, 67.20, 148.5},
{258.72, 72.29, 147.1},
{269.68, 76.51, 147.1},
{281.23, 79.88, 147.1},
{293.29, 81.69, 148.4},
